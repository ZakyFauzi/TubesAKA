Operasi Dasar: Dot Product

Zaky Muhammad Fauzi | 103052400064

Fakultas Informatika, Universitas Telkom

Definisi Matematis Dot Product

Diberikan dua vektor A dan B berukuran n, operasi dot product didefinisikan sebagai:

Dot(A, B) = Σi=1n (Ai × Bi)

Operasi Dasar

  • Perkalian: Ai × Bi
  • Penjumlahan: Hasil perkalian ditambahkan ke akumulator.
  • Total operasi per elemen: 2 Operasi Dasar.

Tujuan Analisis

Menentukan pertumbuhan fungsi waktu T(n) terhadap kenaikan ukuran input n pada dua paradigma berbeda.

Analisis Algoritma Iteratif

Penghitungan Operasi Dasar

Loop berjalan dari i = 0 sampai n-1.

T(n) = Cinit + Σi=0n-1 (Cloop_body)
T(n) = 1 + n × (2)
T(n) = 2n + 1

Notasi Asimtotik

  • Batas Atas (Big-O): O(n)
  • Batas Bawah (Big-Omega): Ω(n)
  • Batas Ketat (Big-Theta): Θ(n)

Pertumbuhan waktu adalah Linear.

Analisis Algoritma Rekursif

Relasi Rekurensi

Masalah berukuran n diselesaikan dengan menyelesaikan masalah berukuran n-1.

T(n) = T(n-1) + C ; untuk n > 0
T(0) = 1 ; Base Case

Metode Substitusi

T(n) = T(n-1) + C

T(n) = [T(n-2) + C] + C = T(n-2) + 2C

T(n) = T(n-k) + kC

Substitusi k = n:

T(n) = T(0) + nC = 1 + nC

Hasil Asimtotik

T(n) mendominasi secara linear.

O(n)

Secara asimtotik sama dengan iteratif.

Kompleksitas Ruang (Space Complexity)

Poin pembeda utama antara kedua algoritma dalam analisis AKA:

Iteratif: S(n) = O(1)

Hanya membutuhkan variabel tunggal (akumulator) yang tidak bergantung pada ukuran n.

Status: Efisien secara memori.

Rekursif: S(n) = O(n)

Setiap pemanggilan fungsi menempati Stack Frame baru hingga mencapai base case.

Status: Risiko penggunaan memori tinggi.

Analisis Efisiensi Konstanta

Meskipun keduanya O(n), hasil eksperimen menunjukkan perbedaan konstanta yang signifikan:

Titeratif(n) < Trekursif(n)

Penyebab Teoritis

  • Overhead: Pemanggilan fungsi memerlukan waktu untuk alokasi parameter dan return address.
  • Iterasi: Operasi lompatan (jump) pada loop jauh lebih ringan di tingkat hardware.

Rasio Perbandingan

2.73x

Lebih Lambat (Rekursif)

Kesimpulan Analisis

  • 1. Kompleksitas Waktu:
    Kedua algoritma memiliki Kompleksitas Linear O(n) secara asimtotik.
  • 2. Kompleksitas Ruang:
    Iteratif jauh lebih unggul dengan O(1) dibandingkan Rekursif O(n).
  • 3. Kesimpulan Akhir:
    Pendekatan Iteratif adalah solusi yang paling tepat dari sisi efisiensi memori dan waktu untuk persoalan Dot Product.
